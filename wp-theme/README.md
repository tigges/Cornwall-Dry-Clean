# WordPress block theme

`cornwall-dry-cleaners` is a full-site-editing theme. The Blue Awning homepage is a block pattern (`cornwall/homepage`) so copy, photos and buttons can be edited in **Appearance → Editor**.

## Install

1. Zip the `cornwall-dry-cleaners` folder.
2. WordPress → Appearance → Themes → Upload Theme → Activate.

Cloudways still needs SSH or a WordPress application password before this can be pushed to `wordpress-1344959-6734053.cloudwaysapps.com`.
