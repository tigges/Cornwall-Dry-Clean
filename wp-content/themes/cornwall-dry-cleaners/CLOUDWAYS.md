# Cloudways Git

This theme is meant to be pulled into a WordPress `public_html/`.

| Field | Value |
| --- | --- |
| Git Remote Address | `git@github.com:tigges/Cornwall-Dry-Clean.git` |
| Branch | `cursor/legal-pages-fed1` |
| Deployment Path | `public_html/` |

Fetch, select that branch, Pull, then **purge Breeze**. Confirm `style.css` shows **1.5.3**. On mobile the header is logo + menu; the number is in the drawer. Call/Directions stay in the bottom bar.
