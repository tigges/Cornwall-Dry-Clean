# Cloudways Git

This theme is meant to be pulled into a WordPress `public_html/`.

| Field | Value |
| --- | --- |
| Git Remote Address | `git@github.com:tigges/Cornwall-Dry-Clean.git` |
| Branch | `cursor/cloudways-public-html-fed1` |
| Deployment Path | `public_html/` |

Fetch, select that branch, Pull, then **purge Breeze**. The live site stays on the previous HTML until cache is cleared.

Theme Version **1.2.4** removes Copy address and opens a little more space before Opening hours. Confirm `style.css` shows that version after Pull.
